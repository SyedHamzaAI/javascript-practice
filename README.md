# javascript-practice
JavaScript Practice From the book A Smarter way to learn JavaScript (Chapter 1-67). 

## Complete Saylani assignment collection

The [saylani-assignments](saylani-assignments/README.md) folder contains all **160 exercises across 19 chapter groups**, covering chapters 1–67 from the [assigned source](https://github.com/nadir-786/saylani-complete-javascript/tree/master/Chapter%201%20to%2067%20(JS)).

Open [saylani-assignments/index.html](saylani-assignments/index.html) locally in your browser to browse chapters and run each question separately. Every question includes readable JavaScript, and the browser exercises include working forms, counters, image modals and editable student tables.

The original chapter folders are preserved. See the collection README for coverage notes, running instructions and checks.
